# 怪叔叔看图

一款面向 Windows 11 的极简无边框参考图查看器：图片置顶、滚轮以鼠标为中心缩放、抓取手势移动窗口，并内置亮度/对比度/饱和度/去噪/锐化调整。

- 当前版本：**4.0.0**
- 技术栈：**WPF / .NET 10（Windows）**
- 许可：**MIT 免费开源**

## 核心功能

- 无边框面板，顶部灵动岛控制条（顶边相切、左右凹肩镜像、底部圆角）；适配按钮为双层图标：目标层在上（图片→窗口用窗口图标，窗口→图片用图片图标）；右上角悬停展开同一个岛形面板，面板上承载置顶与关闭两个按钮。置顶按钮使用 📌 emoji 外形，切换时播放顶入 / 拔出回弹动画
- 图片画布始终裁切到窗口当前客户区，缩放/平移不会越界或遮挡控件
- 图片始终置顶；快捷键 `Shift+Ctrl+Alt+T` 切换
- 滚轮以鼠标位置为中心缩放，窗口尺寸不变
- `Ctrl + 滚轮` 图片与窗口同步缩放（修饰键可改）
- 左键拖动平移图片；右键 / 中键 / 空格+左键使用 Windows 系统手型抓取光标移动窗口
- `Shift+Ctrl+Alt+R` 窗口适配图片，窗口四边与图片当前显示尺寸完全重合、无留白；`Shift+Ctrl+Alt+S` 图片等比适配窗口
- 单窗口 / 多窗口模式；拖拽图片文件到窗口；安装后自动成为图片默认打开程序，并注入“用怪叔叔看图打开”右键菜单
- 图片标注：直线、波浪线、双线、自由画、手绘圈注；笔迹采用可变宽度手绘笔触（端部收细、压力抖动，直线/双线/波浪/圈注均为不规则重叠手绘形态）；“移动”工具可拖动任意已绘制笔迹；橡皮擦支持自由擦除、点击擦除元素、擦头大小调节与一键清空；笔迹以图片归一化坐标保存，缩放/平移时跟随图片
- 三套上下文分层罗盘：默认按住 `Ctrl + 鼠标右键` 拖动唤出；**画布/空白画布**显示软件功能（打开/保存/另存为/截图/置顶/设置/关于/退出），**图片上**显示涂鸦菜单（形状/颜色/透明/粗细/橡皮/AI/截图/工具），**涂鸦元素上**显示编辑菜单（线型/颜色/透明/粗细/截图/复制/删除/退出）
- 罗盘三态高亮与连线触发：同层无激活时全部常规；选中一项后仅该项高亮、同层其他降低对比；被激活的外层以正常状态显示；鼠标移出菜单后连线可触发最外层扇区，若该项有下级则仅以半透明预览展开，不可被线继续触发
- 标注工具：直线、波浪线、双线、自由画、手绘圈注、**油漆桶填充**；支持**标准平滑线**与**手绘笔触线**，标准线覆盖单线/双线/波浪/圆圈；手绘抖动基于图片像素空间固定种子，绘制与缩放时不再跳动；透明度与 PPT 式荧光笔高亮；内置高对比色 + 自定义调色板
- 涂鸦与图片绝对绑定：坐标按图片归一化存储、笔宽按图片像素存储，缩放/平移/窗口变化后笔迹、填充、文字卡片保持与图片一致的位置和相对大小；选中对象显示青色柔光、虚线框与端点手柄
- 截图系统在三套罗盘、顶部灵动岛与全局快捷键中均可使用：全屏、指定窗口、拖动矩形、自由绘制封闭区；截图结果在新置顶窗口显示，GDI 操作有异常保护
- AI 罗盘新增“配置”项直达后台 AI 设置；未配置 API 时翻译/识别提示并跳转配置；支持框选区域翻译与文字识别（含手写）
- 底部白色小条悬停上推为半透明幻灯片岛：预览当前目录或本次拖入批次的其他图片，中间大两侧小，滚轮滚动，单击展开到窗口；窗口左右两侧提供上一张/下一张触发区
- 已绘制元素可编辑：线段拖两端顶点改长度、拖本体移动、圆圈调长宽、自由画只移动、Delete 删除、复制、线型互转（线族之间，不能转成圆圈/自由画）
- 截图钉桌面：仿微信框选截图，确认后以新窗口置顶显示；支持全屏、窗口、矩形与自由封闭区四种方式；支持框选区域翻译与文字识别（含手写），需配置大模型 API
- `.gjpg` 可编辑工程：保存图片与全部标注/填充/翻译/识别痕迹，再次打开自动还原并可继续编辑；保存/另存为菜单可用
- 左下角工具徽标点击弹出向上选择菜单：线型、标准/手绘、线径、透明度、内置颜色与调色板直接选择；悬停仅描边高亮，不再覆盖整块遮罩；画线用钢笔光标、橡皮擦用橡皮擦光标；Esc 退出工具
- 主窗口 / 关于 / 后台设置协同置顶：三者共享置顶开关，任一被激活时升到最上层
- 全局快捷键冲突检测：录制时实时提示是否被占用或系统保留，尝试识别占用程序；启动时托盘气泡提示未能注册的快捷键
- 背景颜色、面板背景透明度（图片不受影响）、圆角、缩放步长等后台设置
- 智能优化预设与一键还原；亮度、对比度、饱和度、边缘保护去噪、锐化
- 统一主题 Logo（龙形 G：墨绿龙首、朱红祥云、米色回纹）已应用到主窗口、设置/关于窗口、托盘、任务栏、资源管理器、任务管理器、快捷方式与安装程序；关于窗口展示同款图标

## 标注罗盘

按住配置的修饰键 + 鼠标键后，罗盘在按下点展开，**内容随当前位置自动切换三套菜单**：

- **画布上（含无图的空白画布）** → 文件（打开/保存/另存为 .gjpg）、截图、窗口（置顶/设置/关于）、退出
- **图片上** → 形状（直线/波浪/双线/自由画/圈注/填充/标准线/手绘线）、颜色（内置高对比色 + 调色板）、透明（高亮/半透明/实心/荧光笔）、粗细、橡皮、AI（配置/翻译/识别）、截图（全屏/窗口/矩形/自由区）、工具（指针/移动/换色/清空/退出）
- **涂鸦元素上** → 线型（改直线/波浪/双线/标准/手绘）、颜色、透明、粗细（加粗/变细）、截图、操作（复制/删除/退出）

把鼠标移到某分类上，外圈展开它的下级；鼠标缩回中心圆收起。悬停任意项弹出"名称 — 说明"提示。连接线为细而精致的流光虚线；同层选中某一项后，其他同层项降低对比，外层已激活项仍保持正常亮度。鼠标落在菜单扇区内时以指针为准；鼠标移出菜单后，连线可触发最外层扇区，带下级的项只以半透明预览展开，鼠标真正落入下级扇区才能激活。

**编辑元素**：切换到"移动"工具或在指针模式下直接点击涂鸦元素即可选中；线段两端出现手柄可拖动改长度，拖动本体移动位置，按 Delete 删除；圆圈通过两角手柄调长宽；自由画只整体移动以保留自然笔触。选中后可用罗盘或左下角徽标改颜色、透明度、线型。

**AI**：在罗盘的"AI"分类选"翻译"或"识别"，然后在图片上框选区域，结果以可移动的翻译/识别卡片叠加显示。需先在后台设置填写兼容 OpenAI 格式的接口地址、模型、密钥与目标语言（可"测试 API 连接"）。

## 支持的格式

直接解码：JPG/JPEG/JFIF/JPE、PNG、BMP/DIB、GIF、WebP、TIFF、ICO、HEIC/HEIF、AVIF、JXL、JP2/J2K、WDP/HDP、EXIF、TGA、PCX、PBM/PGM/PPM/PNM 等。

Windows 缩略图预览：SVG/SVGZ、EMF/WMF、PDF、PSD/AI/EPS，以及 XMind(`.xmind`)、FreeMind(`.mm`)、draw.io(`.drawio`)、Visio(`.vsdx/.vsd/.vdw`) 等流程图与脑图文件。此类文件依赖系统已安装对应软件来生成缩略图，查看的是系统提供的预览位图。

可编辑工程：`.gjpg`（怪叔叔看图标注工程，内嵌原图与全部标注/填充/翻译/识别痕迹，可再次打开继续编辑）。

## 从源码构建

需安装 .NET 10 Desktop SDK：

```bat
封装单文件运行包.bat
封装安装包.bat
```

输出统一位于 `artifacts/`：`artifacts/single/` 只有 `GuaishushuViewer-v<版本号>.exe`，`artifacts/setup/` 只有 `GuaishushuViewer-v<版本号>-Setup.exe`。两个批处理是固定代码，版本号只从 `src/WBImageViewer/WBImageViewer.csproj` 的 `<Version>` 读取；发布暂存目录会在脚本结束时自动删除，仓库根目录不再残留生成产物。安装程序源码位于 `src/WBInstaller/`，它链接查看器的格式清单，内嵌 MIT 许可协议与发布后的主程序。
