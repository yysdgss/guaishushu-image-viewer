# 该怪叔叔看图

一款面向 Windows 11 的极简无边框参考图查看器：图片置顶、滚轮以鼠标为中心缩放、抓取手势移动窗口，并内置亮度/对比度/饱和度/去噪/锐化调整。

- 当前版本：**1.2.0**
- 技术栈：**WPF / .NET 10（Windows）**
- 许可：**MIT 免费开源**

## 核心功能

- 无边框面板，顶部斜刘海控制条，右上角悬停展开关闭按钮
- 图片始终置顶；快捷键 `Shift+Ctrl+Alt+T` 切换
- 滚轮以鼠标位置为中心缩放，窗口尺寸不变
- `Ctrl + 滚轮` 图片与窗口同步缩放（修饰键可改）
- 左键拖动平移图片；右键 / 中键 / 空格+左键以抓取手势移动窗口
- `Shift+Ctrl+Alt+R` 窗口适配图片；`Shift+Ctrl+Alt+S` 图片等比适配窗口
- 单窗口 / 多窗口模式；拖拽图片文件到窗口；注册为图片默认查看方式
- 背景颜色、面板透明度、圆角、缩放步长等后台设置
- 智能优化预设与一键还原；亮度、对比度、饱和度、边缘保护去噪、锐化

## 操作

| 操作 | 效果 |
| --- | --- |
| 鼠标滚轮 | 以鼠标位置为中心缩放图片 |
| Ctrl + 滚轮 | 图片与窗口同步缩放 |
| 左键拖动 | 平移图片 |
| 右键拖动 | 抓取并移动整个面板 |
| Shift+Ctrl+Alt+T | 切换置顶 |
| Shift+Ctrl+Alt+R | 窗口适配当前图片 |
| Shift+Ctrl+Alt+S | 图片适配当前窗口 |
| 顶部刘海 | 置顶 / 适配 / 图片调整 / 设置 / 关于 |
| 右上角悬停 | 展开关闭按钮 |

## 下载

- [单文件运行包（Releases）](../../releases)
- [Windows 安装包 ZIP（Releases）](../../releases)

> 解压安装包后运行 `install.cmd`：它会自动复制程序、创建桌面/开始菜单快捷方式、注册 ProgID 与 OpenWith 候选。由于 Windows 11 保护用户的“默认应用”选择，安装结束时会打开系统自带的“打开方式”窗口，请选择“该怪叔叔看图”并勾选始终使用。

## 从源码构建

需安装 .NET 10 Desktop SDK：

```bat
封装单文件运行包.bat
封装安装包.bat
```

输出位于 `dist/`：单文件程序、IExpress 安装包。
